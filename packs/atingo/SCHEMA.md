# packs/atingo — the pack schema (data, never code; the validator `atingo-path` (L3) and `npm run packs:check` (L1) refuse anything else)

| folder | file | shape |
|---|---|---|
| `goal-kinds/` | `<family>.json` | `{version, family, kinds[{id, title, evidence_kind, verifier, window_days, attestation_fallback}]}`; `evidence_kind` ∈ wallet_balance · receipt · document · entity_row · connector_value · attestation; `verifier` ∈ key_result · eval_suite · script · professional_signoff · attestation. No kind is "mark as done": `verifier: attestation` is allowed only with `attestation_fallback: true` on a kind whose primary evidence is unavailable. |
| `paths/` | `<id>.json` | `{id, tier, title, locale_default, persona?, root, nodes[], edges[], people_kinds_by_node{}, price_ref?, certificate?}`; `tier` ∈ platform · creator · self; a node `{id, goal_kind, lesson_template, blocks_allowed[], evidence, receipt_kind, sources[]}`; an edge `{from, to, kind: prerequisite | branch}`; `certificate` only on `platform`; a `platform` node has ≥ 2 `sources`; every `goal_kind` exists in `goal-kinds/`; every `blocks_allowed` entry is a kind of the kernel's block pack; every people kind exists in the kernel's `goal-kinds.json`. |
| `motives/` | `motives.json` | `{version, motives[{id, line, promise, entry_paths[], targeting: "declared_goal_only"}]}`; refused anywhere: a `segment` field; a key or value naming a protected ground (gender, age, health, faith, nationality, orientation, disability — massrelay D197). |
| `personas/` | `<key>.json`, `evals/<key>.json` | the kernel's agent definition verbatim `{key, persona, taskTemplate (<= 1200 chars), toolConfigRef, evalSetRef}` plus `atingo{path_families[], voice, never[]}`; the path names it (`persona`); the taskTemplate may not instruct marking a step done, promising or guaranteeing an outcome, writing markup, rating or scoring the learner, or deriving a protected ground; the eval set is a JSON array of `{id, prompt, mustContain[], mustNotContain[], intent, why}`, >= 12 cases. |
| `lesson-templates/` | `<id>.json` | `{id, title, items_kind: "steps", template{title, step_prompt, evidence_hint, steps_per_lesson, review_max}, levels[{id, steps[{prompt, evidence_hint}] (>= 3)}]}`; prompts only, no model-written prose; every node's `lesson_template` has a file; two nodes may share one. |
| `follow-up/` | `<path_id>.json` | `{path_id, nodes{node_id: {rrule, grace_days, nudges[{after_hours, channel, template_id}], escalate{after_days, to}, pause_rules[]}}}`; `rrule` is the kernel's subset (FREQ=DAILY/WEEKLY/MONTHLY/YEARLY, INTERVAL, COUNT); `channel` is a kernel nudge channel; `escalate.to` is one of the node's people kinds; one row per node. |
| `evidence/` | `<path_id>.json` | `{path_id, nodes{node_id: {verifier, binding{connector_id?, method_id?, eval_set?, script_ref?, expect?{field, op, value}}, fallback: attestation \| none, sources_of_truth[]}}}`; `verifier` is a kernel verifier kind; `attestation` (verifier or fallback) only when the node's goal kind has `attestation_fallback: true`; the binding's connector is in `sources_of_truth`; one row per node. |
| `curricula/` | `<path_id>/` | the platform tier's locked content: `sources.csv` (node_id, url, licence, retrieved_at), `price.json` (the kernel's price row id), `CHANGELOG.md`. Closed (D7). |
| `i18n/` | `<path_id>.<locale>.json` | `{path_id, locale, nodes{node_id: {title, lesson{steps[{prompt, evidence_hint}]}}}}` — the LOCALE layer (`locale` ∈ kernel-pins `locales`: id · en); one entry per path node, step count equal to the node template's `levels[0].steps` (it never adds or removes a step), no empty string; codes `i18n_path_unknown` · `i18n_locale_unsupported` · `i18n_node_unknown` · `i18n_node_missing` · `i18n_steps_count_mismatch` · `i18n_empty_string`; the GLOBAL layer is the path file; the COUNTRY layer is the kernel's `countries/<ISO>.json`. The three never mix. |
| `review/` | `<path_id>.json` | `{path_id, nodes{node_id: {engine: "fsrs", desired_retention, max_interval_days, first_interval_days?, items_from: lesson_steps\|graph_items}}}` — the REVIEW layer (L20, D17): when an item a learner got wrong comes back, computed by FSRS-6 (`atingo_path::review`, the `fsrs` crate, BSD-3-Clause) from the review history inside this policy; `desired_retention` strictly inside (0.5, 0.99), `first_interval_days` (default 1) is the interval after no history; opt-in by folder (no `review/` = silent, with it a node without a row warns); codes `review_policy_missing` (warning) · `review_engine_unknown` · `review_retention_out_of_range`. A review is practice scheduling, never proof. |
| `prices/` | `<price_ref>.json` | the PRICE row in the kernel's price shape (L7, handover 1.13): `{id, country, currency, amount, amount_mu, tax{kind, rate_bp}, rails[], period: one_off \| monthly}`; `currency` and `amount` stay at the top level (the public page reads them); `amount` is whole currency units, `amount_mu` its micro-units (`amount` x 1,000,000, a whole rupiah); `country` has a row in `kernel-pins.json` `countries` (a pinned copy of the kernel's `countries/<ISO>.json`, `confirmed:false` until the founder confirms it, handover 1.14); codes `price_ref_unresolved` (a path's `price_ref` has no row) · `price_currency_not_allowed` · `price_amount_not_whole` · `price_rail_not_allowed` · `price_country_unknown`. A priced platform path still needs two sources per node (`sources_missing_when_priced`). The row is a draft until the kernel's price book holds it. |
| `graph/` | `sectors.json`, `occupations/<sector>.json`, `competencies/<sector>.json` (+ `*.hand.json`), `items/<competency>.json`, `lessons/<path>/<node>.json`, `sources/<sha-prefix>.json`, `ATTRIBUTION.md` | the knowledge graph (spec 03 §2–§3, L16). `sectors`: `{version, onet_release, sectors[{id: sector:<slug>, title, regulated, job_families[], note}]}`; `occupations`: `{version, occupations[{id: occ:<soc>, title, description (<=200), job_family, job_zone, part_of, top[{comp, element, importance}]}]}`; `competencies`: `{version, competencies[{id: comp:<slug>, title, kind, onet_element?, part_of, requires[], occupations[]}]}`; `items`: `{version, competency, items[{id: item:<topic>/<slug>, kind, text, sources[{url,title,licence,retrieved_at,sha256}], jurisdiction?, valid_until?, badge?}]}`; `lessons`: `{version, lessons[{id, path, node, title, steps[{prompt, evidence_hint, item}]}]}`; `sources`: `{url,title,licence,retrieved_at,sha256,bytes,normalize?}` (never the body). `occupations/` and the `<sector>.json` competency files are generated by `tools/curricula/seed-onet.mjs`; `*.hand.json` is ours. Rules (both validators, same codes): `graph_parent_missing` · `graph_requires_cycle` · `graph_item_sources_lt_2` · `graph_item_source_unfetched` · `graph_figure_without_valid_until` · `graph_regulated_unbadged` · `graph_regulated_claim_verb` (`guaranteed`, `will earn`, `cures`, `risk free`) · `graph_competency_orphan` · warning `graph_valid_until_past`. |

Rules: a folder holds only the files above; ids are slugs; a correction is a new version (`CHANGELOG.md`), never an edit of a sold curriculum.
